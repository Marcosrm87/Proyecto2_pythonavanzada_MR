

# Proyecto de Procesamiento de Imágenes
## Descripción

Proyecto desarrollado en Python para la manipulación, procesamiento y análisis de imágenes digitales.

## Tecnologías utilizadas

- Python
- Pillow
- NumPy
- Matplotlib
- OpenCV
- OS
  
## Funcionalidades

La aplicación permite realizar distintas operaciones de procesamiento de imágenes digitales:

 - Redimensionamiento: adaptación de imágenes a las dimensiones requeridas por diferentes redes sociales.

- Ecualización: mejora del contraste de las imágenes mediante técnicas de procesamiento digital.

- Filtros artísticos: aplicación de efectos visuales utilizando Pillow.

- Detección de bordes y contornos: procesamiento de imágenes mediante OpenCV.

- Selección de imágenes: posibilidad de cambiar la imagen sobre la que se realizan las operaciones.

- Menú interactivo: navegación por las distintas funcionalidades mediante opciones seleccionables.

## Estructura del proyecto

El proyecto se organiza en los siguientes archivos principales:

fotoapp.py: contiene las funciones de procesamiento de imágenes, el menú interactivo y la función principal main().

fotoapp_testdev.ipynb: importa y ejecuta la función main() para iniciar la aplicación.

Las imágenes utilizadas y las imágenes generadas se organizan en sus respectivas carpetas.

## Instalación y ejecución

## Requisitos previos

Es necesario tener Python instalado y contar con las siguientes bibliotecas:

- Pillow

- NumPy

- Matplotlib

- OpenCV

## Instalación de dependencias

Las bibliotecas pueden instalarse mediante el siguiente comando:

  pip install pillow numpy matplotlib opencv-python

## Ejecución

La aplicación se ejecuta desde el notebook Jupyter:

fotoapp_testdev.ipynb

Para utilizarla, abrir el archivo en Jupyter Notebook o Visual Studio Code y ejecutar las celdas en orden.
