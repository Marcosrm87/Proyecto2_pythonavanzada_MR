

# Proyecto de Procesamiento de Imágenes
## Descripción

Proyecto desarrollado en Python para la manipulación, procesamiento y análisis de imágenes digitales.

## Tecnologías utilizadas

- Python
- Pillow
- NumPy
- Matplotlib
- OpenCV
  
## Funcionalidades

La aplicación permite realizar distintas operaciones de procesamiento de imágenes digitales:

 - Redimensionamiento: adaptación de imágenes a las dimensiones requeridas por diferentes redes sociales.

- Ecualización: mejora del contraste de las imágenes mediante técnicas de procesamiento digital.

- Filtros artísticos: aplicación de efectos visuales utilizando Pillow.

- Detección de bordes y contornos: procesamiento de imágenes mediante OpenCV.

- Selección de imágenes: posibilidad de cambiar la imagen sobre la que se realizan las operaciones.

- Menú interactivo: navegación por las distintas funcionalidades mediante opciones seleccionables.
